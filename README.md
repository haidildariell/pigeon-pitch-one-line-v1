## The pitch

> I'm raising a seed round — literally, seeds — for Statuebnb: premium perches above every monument, and our guests never check out, they just poop and leave.

## How it works

`main.py` (Python standard library only) writes that single line to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
